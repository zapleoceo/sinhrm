# SEC-mime-2026-45070 — security dependency remediation

## Context and source

Foundation PR #247's security job reported `symfony/mime` v7.4.19 with advisory CVE-2026-45070. Symfony's official
correction dated 2026-10-29 says its earlier fixed-version claim was wrong: the fix entered maintained 7.4 in v7.4.22.
The issue is MIME email-header injection through non-token parameter names, when an application derives those names from
untrusted input. The vendor's fix rejects names outside the RFC token character set.

- [Symfony correction, 2026-10-29](https://symfony.com/blog/about-the-security-entries-in-symfony-5-4-55-6-4-49-7-4-22-and-8-1-10)
- [CVE-2026-45070 description](https://symfony.com/blog/cve-2026-45070-email-header-injection-via-non-token-characters-in-mime-parameter-names)
- [Symfony 7.4.22 release](https://symfony.com/blog/symfony-7-4-22-released)
