# Внешний вид

Страница `/settings/appearance` доступна вошедшему пользователю через меню «Зовнішній вигляд», независимо от административной роли. Изменения применяются сразу, не требуют API или повторного входа. Можно выбрать системную/светлую/тёмную тему, свою либо Sintegrum OS палитру, акцент, стеклянный или сплошной стиль, обои, прозрачность0–40%, уменьшение движения и быстрый режим. Сброс возвращает исходные предпочтения.

Настройки действуют на весь интерфейс: общие Material компоненты, страницы, формы и overlays используют semantic tokens. Стекло ограничено системной оболочкой; рабочие данные остаются на читаемой подложке. Fast mode использует непрозрачные поверхности без эффектов, в том числе на телефоне; старые браузеры получают opaque fallback. Контраст цветов, включая действие snackbar на обратном фоне, проверяет frontend/scripts/contrast-check.mjs.

Форма типизированная, standalone/OnPush, UK/RU/EN. Изменения ThemeService извне синхронизируются без feedback loop; обновляются только отличающиеся controls. Scheme и wallpaper — Material-styled native selects: их выбранные значения остаются связаны с typed controls даже пока асинхронно загружаются переводы или меняется язык. Хранение — только косметический JSON в браузере, при запрете storage текущие настройки продолжают работать. Одна authority и миграция старой темы описаны в [Core](core.md), детали token bridge — [Theme](theme.md). Тесты service/page покрывают миграцию, неверные значения, ограничения, blocked storage, внешнюю смену темы и отложенную загрузку переводов; CI ui-parity содержит страницу и отдельные flow сохранения и mobile fast mode.

Этот foundation не реализует отдельные окна и desktop widgets. Их этапы и фактическое состояние: [общая задача](../tasks/HRM-11_system-os-redesign.md).
