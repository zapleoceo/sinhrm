# «Мої задачі» (фронтенд `features/tasks`)

## Что это и зачем
Одна страница со всеми своими задачами: напоминания рекрутинга, шаги воркфлоу (онбординг/офбординг) и «ознайомитися з
документом». Отметил — готово; задача воркфлоу при этом закрывает свой шаг.

## Как пользоваться
Меню → **«Мої задачі»** (`/tasks`): фильтр по источнику (усі / рекрутинг / воркфлоу / документи / опитування — задачи «настрій команди знизився»
руководителю, [pulse.md](pulse.md)), по сроку (усі /
сьогодні / прострочені), «показати виконані». Галочка доступна исполнителю задачи (любая роль) и рекрутерам/админам,
которые её видят. У задач документов галочки нет — кнопка ведёт в «Мої документи», где нажимается «Ознайомлений».
Ссылка задачи открывает профиль, вкладку документов или внешнюю форму (в новой вкладке).

## Как устроено
Бэкенд — общая таблица `tasks` и `GET/PATCH /api/tasks` модуля Scripts ([scripts.md](scripts.md), раздел «Общий
список задач»), параметр `source`. Фронт: `my-tasks.page.ts` использует `TasksStore`/`TasksWidget` из
`features/scripts/tasks` (правило галочки — `canCompleteTask`: writer рекрутинга или исполнитель). Строки — `tasks.*`,
`scripts.tasks.type.*`.

## Как проверить
`tasks.spec.ts`, `scripts.stores.spec.ts`; вручную: запустить воркфлоу с шагом «створити задачу» на себя → после
`workflows.tick` задача на `/tasks` → отметить → шаг «Виконано» на доске воркфлоу.
