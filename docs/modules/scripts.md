# Модуль «Скрипты» — редактируемые скрипты рекрутера + AI-оценка

Источник первой версии: Google Doc «Гайд для рекрутера філії: скрипт дзвінка кандидату (UA)».
Скрипты НЕ зашиваются в код — хранятся в БД, редактируются в админке, версионируются.

## Структура скрипта (из документа)
- **Скрипт звонка** — цель (7 минут → договориться о 1-м этапе), 3 правила рекрутера,
  шаги: 1 Приветствие (А: нашли резюме / Б: отклик) → 2 Интерес к кандидату → 3 О компании →
  4 Вакансия и условия → 5 Отбор (акцент на e-собеседовании Sintegrum, альтернатива — филиал) →
  6 Фиксация следующего шага (онлайн / филиал / не может выбрать) → 7 Вопросы → 8 Завершение.
- **Возражения** — 5 шт. («не люблю с роботом», «40–90 мин долго», «если неудачно отвечу»,
  «зачем», «какая зарплата») с эталонными ответами.
- **Скрипт переписки** — сообщение 1, 2А (онлайн), 2Б (филиал), 2В (не может выбрать),
  «не взял трубку».
- **Напоминания (follow-up)** — через 1 день, через 1–2 дня после ссылки, последнее через 3–4 дня.

## Модель данных
`script(id, name, channel: call|chat, vacancy_type?, active_version_id)`
`script_version(id, script_id, version, published_at, author)` — правка = новая версия, старые
оценки остаются привязаны к своей версии.
`script_step(version_id, order, title, goal, sample_text, required: bool, weight, check_hint)`
`script_objection(version_id, trigger, sample_answer)`
`script_template(version_id, key, text с переменными {Ім'я}, {вакансія}, {посилання}, {адреса})`
`followup_rule(version_id, condition, delay_days, template_key)`
`script_evaluation(touchpoint_id, script_version_id, score, step_results[{step, done, quote}],
objections_handled, next_step_fixed: bool, recommendations)`

## Что делает продукт
1. **Редактор** в админке: шаги, обязательность и вес, эталонные фразы, возражения, шаблоны,
   правила напоминаний; предпросмотр; публикация версии.
2. **Подсказки рекрутеру** в карточке: шаблоны сообщений в один клик с подстановкой имени,
   вакансии, ссылки на e-собеседование, адреса филиала.
3. **AI-оценка** каждого звонка (транскрипт) и переписки: какие шаги пройдены (с цитатой),
   обработаны ли возражения, **зафиксирован ли конкретный следующий шаг** (главное правило),
   предложено ли e-собеседование первым; балл, рекомендации. Промпт = активная версия скрипта
   (стабильная часть → prompt caching), переписка — в конце.
4. **Автонапоминания**: задача рекрутеру (или авто-сообщение, когда канал подключён) по правилам
   follow-up, если кандидат молчит / не прошёл e-собеседование.
5. **Отчёты**: средний балл по рекрутерам и шагам, конверсия «звонок → записан на 1-й этап»
   в разрезе прохождения скрипта.
