# Секреты и персональные данные

## Простыми словами
Код проекта открыт всем. Поэтому **ни одного пароля или токена в коде нет**. Все ключи от внешних сервисов
(почта, AI, мессенджеры, телефония) суперадмин вводит в админке «Интеграции»; система хранит их в базе
в зашифрованном виде и никому не показывает повторно.

## Что где хранится
| Что | Где | Почему |
|---|---|---|
| `DB_URL`, `APP_KEY`, `SUPERADMIN_EMAIL` | переменные окружения Vercel | без них приложение не может стартовать и расшифровать остальное |
| Токены интеграций (AI Broker, OpenRouter, Google, Sintegrum API, Telegram, телефония…) | таблица `integration_secrets`, шифрование `APP_KEY` (AES-256, `Crypt`) | меняются из админки без деплоя |
| Справочники компании, сотрудники, кандидаты | Postgres (Neon) | в репозиторий не попадают никогда |
| Демо-данные для тестов и preview | фабрики (синтетика) | реальные данные вне prod запрещены |

## Правила
1. Секрет никогда не пишется в код, логи, ответы API, описание PR и документацию.
2. CI запускает `gitleaks` на каждом PR; в репозитории включены GitHub secret scanning и push protection.
3. Preview-окружения и тесты работают **только на синтетических данных** — ветка БД preview не копирует prod.
4. Ротация `APP_KEY`: новый ключ в `APP_KEY`, старый — в `APP_PREVIOUS_KEYS`, затем команда перешифровки секретов.
5. Персональные данные кандидатов обрабатываются по Закону Украины «О защите персональных данных» (№2297-VI):
   кандидат уведомляется о хранении, есть экспорт и удаление по запросу, доступ — по ролям и филиалам.
