# SinHRM — документация

**Что это.** SinHRM — система для рекрутеров и HR, наследник Sintegrum. Главная идея: весь путь кандидата
(откуда пришёл → этапы отбора → оффер или отказ) и **все касания с ним** (звонки, мессенджеры, почта, встречи)
видны в одной карточке. Руководитель видит, кто из кандидатов «завис» без внимания и насколько рекрутер
следует скрипту разговора.

Проект тестовый и некоммерческий. Код открыт (публичный репозиторий), **данные и секреты — только в базе**.

## Как устроено одним абзацем
Интерфейс — Angular-приложение на `sinhrm.vercel.app`. Все запросы `/api/*` браузер отправляет на тот же адрес,
а Vercel незаметно пересылает их в API на Laravel (`sinhrm-api.vercel.app`). API хранит данные в Postgres (Neon,
Франкфурт). Фоновые задачи (почта, напоминания) запускаются по расписанию из GitHub Actions.
