# ADR 0006 — Фоновые задачи: cron в GitHub Actions + ops-эндпоинты

**Статус:** принято (2026-09-26). Подробности — [guides/deploy.md](../guides/deploy.md), [modules/core.md](../modules/core.md).

**Контекст.** Нужны периодические задачи (почта, напоминания, SLA, воркфлоу, волны опросов). Cron Vercel Hobby —
раз в сутки; у GitHub нет доступа к БД.

**Решение.** `.github/workflows/cron.yml` каждые 30 минут (`*/30 * * * *`, `concurrency: cron-jobs`) вызывает
`POST /api/ops/jobs/run` с заголовком `X-Ops-Secret`; API сам выполняет все зарегистрированные
`Core\Contracts\ScheduledJob`. Миграции — тем же способом: `POST /api/ops/migrate` из `deploy.yml`. Группа `ops`
закрыта middleware `RequireOpsSecret`. В публичный лог Actions попадают только итог и счётчики.

**Последствия.** Расписание бесплатное и лежит в репозитории; точность — «около 30 минут», GitHub может задерживать
запуски. Каждое задание обязано быть идемпотентным и переживать пропуски (окна дат, атомарный захват).

**Альтернативы.** Vercel Cron (на Hobby — раз в сутки), внешний cron-сервис (ещё один секрет у третьей стороны),
постоянный воркер — нет сервера.
