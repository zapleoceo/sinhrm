# ADR 0003 — Каналы: только вебхуки, один путь приёма через `TouchpointIngestor`

**Статус:** принято (2026-09-26). Подробности — [modules/channels.md](../modules/channels.md).

**Контекст.** Сообщения и звонки кандидатов приходят из Telegram, WhatsApp, Viber, телефонии и почты. Хостинг —
serverless (Vercel, [ADR 0001](0001-hosting-and-stack.md)): нет воркеров и постоянных соединений.

**Решение.** Приём — только входящие вебхуки `POST /api/webhooks/{key}` (тело до 1 МБ, throttle, выключенный канал
→ 404, `adapter.verify()` → 403). Адаптер канала лишь проверяет подпись и превращает payload в события; дальше
**все** пути — вебхук, демо-событие (`/simulate`), отправка из карточки, почтовый агент — идут в один контракт
`Recruiting\Contracts\TouchpointIngestor::ingest` (`MatchingTouchpointIngestor`): сопоставление с кандидатом
(ветка разговора → телефон / e-mail / username), иначе «Вхідні». Идемпотентность — уникальный индекс
`touchpoints(channel, external_id)`.

**Последствия.** Новый канал — новый адаптер, ядро не меняется; повторы и гонки доставки не дублируют касания; демо
проходит тот же код, что и прод. Каналы, которым нужно постоянное соединение (Telegram userbot, long polling),
недоступны до собственного сервера.

**Альтернативы.** Своя логика сопоставления в каждом канале — отклонено (расхождения, дубли); polling или userbot
на воркере — невозможно на Vercel Hobby.
